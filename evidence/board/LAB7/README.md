# LAB7 FPGA/combined board evidence

This directory contains the actual LAB7 scope, serial, wiring, photograph, and
video evidence collected for Tasks 8–12:

- `task8/`: STM32 SPI master UART and oscilloscope captures
- `task9/`: our group acting as both STM32 receiver and transmitter
- `task10/`: STM32-to-FPGA wiring and MCU transmit UART capture
- `task11/`: FPGA-to-STM32 scope and STM32 receive UART captures
- `task12/`: shared wiring plus our-group receive/transmit photographs and videos

Current status: Tasks 8–12 were performed. The proof boundary is not identical
for every direction: Task 10 FPGA reception is user-confirmed without a separate
FPGA RX capture, and the Task 9 transmit direction has no local counterpart RX
log. See
[`reports/_automation/LAB7_POST_EVIDENCE_MANIFEST.md`](../../../reports/_automation/LAB7_POST_EVIDENCE_MANIFEST.md)
for the path mapping and evidence classification. Do not infer unrecorded results
from wiring photographs alone.
